# Theo dõi duyệt từng task

- Task 1 — Cấu trúc mobile/api/admin: đã duyệt.
- Task 2 — Kết nối Expo → API → database: người dùng xác nhận thành công.
- Task 3 — Database tài khoản, hồ sơ, phiên và OTP: người dùng xác nhận hoàn thành; 18 bài kiểm thử đạt.
- Task 4 — Bộ giao diện và thành phần dùng chung: đã duyệt triển khai tiếp Task 5.
- Task 5 — Đăng ký, OTP email, đăng nhập, khôi phục phiên, đăng xuất và Home: đã triển khai, chờ người dùng kiểm tra trên thiết bị với SMTP của dự án.
- Task 6 và các task sau: chưa triển khai, chờ duyệt riêng.

Mỗi task hoàn thành phải báo kết quả và chờ duyệt trước task tiếp theo.
